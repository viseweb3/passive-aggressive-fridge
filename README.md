One dry, petty note from a smart fridge to its owner: the yogurt expired Tuesday, and the fridge kept it cold out of respect while its owner kept it out of denial. Written for make.fun's "Notes From a Passive-Aggressive Fridge" bounty — a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen.

## Run it

```sh
node main.ts
```

It writes the note to `/output/entry.txt` — one line, 85 characters, plain UTF-8.
